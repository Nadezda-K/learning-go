# Go Practice Exercises

A Go learning project containing small programming exercises and supporting shell tasks.

## Task

Practice Go fundamentals by implementing focused functions for calculations, text manipulation, collections, and structured data, alongside basic command-line exercises.

## What the code does

This folder contains independent exercises and experiments rather than one application:

- **Numbers and algorithms:** factorials, Fibonacci numbers, powers, prime checks, greatest common divisors, least common multiples, and combinations.
- **Strings and runes:** reversing and comparing strings, changing case, splitting and joining text, finding substrings, and alphabet transformations.
- **Conversions:** parsing integers, converting number bases, casting values, and converting time units.
- **Slices and matrices:** sorting, filtering, removing duplicates, generating ranges, transposing matrices, and building Pascal's triangle.
- **Structs and geometry:** working with points, rectangles, circles, student scores, and contestants.
- **Shell practice:** navigating directories, listing and finding files, counting results, and using loops. `theDirectory/`, its archive, and `hay.txt` support these exercises.

## Use the exercises

Read each file as a separate task. Some files contain executable examples; others define functions to call from a separate exercise program or test.

For example, with Go installed, run the string-comparison demonstration from this folder:

```bash
go run strcompare.go
```

The folder mixes packages, alternative implementations, and repeated function names, so it is not set up to build as a single Go package. Select an individual exercise and its required supporting definitions when experimenting.

## Learning focus

Go syntax, types, functions, loops, recursion, runes, slices, structs, algorithm design, and basic shell commands.
